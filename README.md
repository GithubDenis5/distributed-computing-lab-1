**Отчёт по лабораторной работе №1**

**1. Множество Мандельброта**

**1. Описание алгоритма**

Программа ищет заданное количество точек, принадлежащих множеству Мандельброта.

Для проверки каждой точки используется итерационная формула с ограничением в 100 итераций. Если значение выходит за установленную границу, точка считается не принадлежащей множеству.

Координаты точек формируются последовательно на сетке с шагом 0.001.

**2. Реализация**

Количество потоков передаётся через аргумент командной строки.

Каждый поток проверяет собственную последовательность точек. Распределение выполняется по формуле: index = iteration \* nthreads + thread\_id Потоки не проверяют одинаковые точки. Найденная точка записывается в общий массив с помощью mutex, счетчик найденных точек также блокируется с помощью mutex при увеличении.

Результаты записываются в points.csv. Для каждой найденной точки сохраняются координаты, номер потока и время проверки.

**2. Задача N тел**

**1. Описание алгоритма**

Программа моделирует движение материальных точек под действием взаимного гравитационного притяжения.

Для каждого тела из входного файла считываются масса, начальные координаты и скорость.

Расчёты выполняются в двумерном пространстве, координаты Z и соответствующие скорости не используются.

На каждом шаге рассчитываются силы притяжения между телами, после чего определяются ускорения и обновляются координаты и скорости методом Эйлера первого порядка.

Шаг моделирования составляет 1 секунду.

Для уменьшения количества вычислений используется третий закон Ньютона. Взаимодействие каждой пары тел рассчитывается только один раз, а полученная сила учитывается для обоих тел с противоположными знаками.

**3. Параллельная реализация**

В программе используется 5 потоков pthread.

Тела распределяются между потоками примерно поровну. Каждый поток рассчитывает взаимодействия для своей группы тел.

Для исключения конфликтов при записи сил используются отдельные массивы для каждого потока.

Синхронизация выполняется с помощью барьеров, реализованных через mutex и условную переменную, так как на MacOS нет поддержки pthread\_barrier\_t

На каждом временном шаге потоки:

1. Рассчитывают силы взаимодействия.
2. Ожидают завершения расчётов остальных потоков.
3. Суммируют силы и обновляют координаты своих тел.
4. Синхронизируются перед записью результатов.

Координаты всех тел записываются в output.csv
